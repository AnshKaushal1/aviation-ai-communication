# ✈️ Aviation AI Communication

🤖 **AI-Assisted Passenger Communication Workflow for Flight Disruptions**

Combining prompt engineering, source verification, and human review to create accurate, clear, and consistent passenger communications.

---

## 🎯 1. Business Problem

Airline service teams must communicate changing flight information clearly and consistently across multiple channels. Incorrect timings, unsupported benefit claims, and inconsistent messages can lead to passenger confusion and dissatisfaction.

This project explores a structured approach to using AI for drafting, verifying, and updating passenger communications through **fictional flight disruption scenarios**.

## 🚀 2. Key Features

* 📧 **Multi-Channel Communication:** Passenger emails, airport announcements, SMS alerts, and service desk responses.
* 🧠 **Prompt Engineering:** Comparison of six different prompting strategies.
* 🔍 **Fact Verification:** Source-based checks to identify factual errors and unsupported claims.
* 🔄 **Dynamic Updates:** Revising passenger communications when operational timings change.
* 🌐 **Bilingual Consistency:** English–Hindi translation and consistency verification.
* ♻️ **Reusable Prompt Template:** Testing a reusable email prompt on a separate flight scenario.

## ⚙️ 3. Project Workflow

1. 📋 Establish flight details, applicable policies, and missing information.
2. ✍️ Draft passenger messages using structured AI prompts.
3. ✅ Evaluate accuracy, completeness, clarity, and tone.
4. 🔎 Correct unsupported claims and adapt messages for different audiences.
5. 🕒 Update all communications when flight timings are revised.
6. 🌐 Verify English–Hindi consistency and test prompt reuse on a new scenario.

## 🛫 4. Verification Scenarios

| **Scenario**                     | **Verification Requirement**                                                                                                                               |
| -------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 🕑 **SB204: Initial Delay**      | Scheduled departure: 2:00 PM; expected departure: 4:30 PM. Calculate the 2-hour-30-minute delay and assess eligibility under the fictional voucher policy. |
| 🕔 **SB204: Revised Timing**     | Expected departure changes to 5:15 PM. Replace earlier estimates and use the revised 4:15 PM passenger update.                                             |
| ❓ **Unconfirmed Information**    | Flag missing gate, refund, or hotel details without inventing answers.                                                                                     |
| ⚠️ **Departure Guarantee**       | Distinguish estimated departure times from confirmed or guaranteed timings.                                                                                |
| 🛩️ **SB310: Voucher Threshold** | Scheduled departure: 10:00 AM; expected departure: 11:15 AM. Confirm the 1-hour-15-minute delay is below the fictional two-hour voucher threshold.         |

AI is used to assist with drafting, evaluation, and translation. The contributor independently verifies source facts, documents corrections, and reviews the final outputs before approval.

🔒 **Disclaimer:** This project uses fictional flight information and policies. It is not connected to live airline systems, and no messages are sent to actual passengers.
